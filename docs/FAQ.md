## Importer un texte : Scan Classique ou Scan Premium ?

### Quelle est la différence ?

| | Scan Classique | Scan Premium |
|---|---|---|
| Prix | Gratuit | Compte Premium |
| Personnages | Vous les saisissez avant l'analyse | Détectés automatiquement |
| PDF avec texte sélectionnable | Oui, quasi instantané | Oui |
| PDF scannés ou photographiés | OCR local, plus lent | Oui, via l'IA |
| Durée indicative (script d'environ 50 pages) | Quelques secondes | Environ 45 secondes |

### Quand choisir le Scan Classique ?
Votre PDF est un texte numérique (vous pouvez sélectionner et copier les mots) et vous connaissez la liste des personnages. C'est le plus rapide.

### Quand choisir le Scan Premium ?
- Vous ne voulez pas saisir les personnages : ils sont détectés automatiquement.
- Votre PDF est un scan ou une photo de pages.
- La mise en page est difficile (répliques coupées entre deux pages, etc.).

### Pourquoi le Scan Premium est-il plus lent ?
Une IA relit tout le script et le restitue réplique par réplique. Pour gagner du temps, le PDF est découpé en parties traitées simultanément ; la progression indique le nombre de parties terminées.

### Que signifie le message « Votre PDF est lisible » ?
Votre PDF contient du texte natif : le Scan Classique (gratuit) suffit. Le Scan Premium fonctionne quand même.

### Pourquoi voit-on des personnages comme « TOUT LE MONDE » ou « SAM + NOLAN » ?
Ce sont des répliques dites en groupe dans le script. Elles sont conservées telles quelles.
