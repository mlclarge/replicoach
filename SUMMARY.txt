                            📋 RÉSUMÉ EXÉCUTIF
================================================================================

OBJECTIF RÉALISÉ:
  Permettre aux comédiens de configurer des délais avant/après leur réplique
  en mode audio pour adapter le rythme de la scène à leur besoin.

FONCTIONNALITÉS IMPLÉMENTÉES:
  ✅ Délai avant MA réplique     (0-3 secondes, boutons rapides)
  ✅ Délai après MA réplique     (0-3 secondes, boutons rapides)
  ✅ Persistance localStorage    (survit aux rafraîchissements)
  ✅ Aperçu audio simulé         (affiche durée totale)
  ✅ Interface utilisateur        (Profile → Onglet "🔊 Audio")

Key:            "audioPreferences"
Format:         JSON object

Default Values:
  {
    "delayBeforeMine": 0,
    "delayAfterMine": 0,
    "delayBeforeNext": 0  // Réservé v1.1
  }

Survit à:       Page refresh, fermeture navigateur, changement de script
Persiste via:   Zustand store + localStorage sync
Charge via:     useAuthStore().loadAudioPreferences()

Q: "Les délais ne s'appliquent pas"

Q: "Rien ne persiste"
A: Cliquer "💾 Sauvegarder", vérifier localStorage dans DevTools
